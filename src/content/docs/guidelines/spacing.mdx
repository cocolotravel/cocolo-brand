Spacing is the quietest part of the system and the one that most determines whether
a layout feels calm or cramped. One scale, used consistently, does most of the work.

<SpacingScale />

## Using spacing

Prefer generous space over decoration. The cloud aesthetic depends on room to
breathe — when a layout feels off, the answer is more often spacing than another
element. Use the scale steps rather than ad-hoc values so rhythm stays consistent
across pages and apps.
